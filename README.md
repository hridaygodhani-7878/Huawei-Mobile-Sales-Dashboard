# Huawei Mobile Sales Dashboard | Power BI

## 📊 Project Overview
An interactive Power BI dashboard developed to analyze Huawei mobile sales performance, customer ratings, payment methods, product trends and geographical sales distribution.

## 📈 Key Metrics
+----------------+-------+
| KPI            | Value |
+----------------+-------+
| Total Sales    | 769M  |
| Total Quantity | 19K   |
| Transactions   | 4K    |
| Average        | 40K   |
--------------------------

## 🚀 Key Features
- Sales performance and trend analysis.
- City-wise geographical sales visualization.
- Customer ratings analysis.
- Payment method comparison.
- Brand and mobile model performance.
- Interactive filters and slicers.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- DAX
- Data Visualization
- Interactive Dashboards
